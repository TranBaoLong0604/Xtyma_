# Contributing to Xtyma_

## Development Workflow

Mỗi tính năng mới nên được phát triển và kiểm tra trước khi commit.

### Quy trình

1. Tạo branch cho tính năng.
2. Phát triển tính năng.
3. Kiểm tra tính năng.
4. Commit thay đổi.
5. Push branch lên GitHub.
6. Merge vào main sau khi hoàn thành.

## Branch Naming

Ví dụ:

- feature/authentication
- feature/student-management
- feature/grade-management
- feature/teacher-dashboard
- feature/student-dashboard
- feature/study-streak

## Commit Convention

Sử dụng các prefix:

- `feat:` thêm tính năng mới
- `fix:` sửa lỗi
- `docs:` cập nhật tài liệu
- `refactor:` cải thiện code
- `test:` thêm hoặc sửa test
- `chore:` công việc cấu hình

Ví dụ:

```text
feat: add student management
fix: prevent students from editing grades
docs: update database documentation
